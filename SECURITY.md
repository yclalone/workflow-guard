# Security policy

## Supported versions

Until the first stable release, only the latest release receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could put users at immediate risk. Instead, use GitHub's private vulnerability reporting feature for this repository. Include the affected version, a minimal reproduction, and the potential impact.

Reports should receive an acknowledgement within seven days. After triage, the maintainer will share the expected remediation and disclosure timeline.
